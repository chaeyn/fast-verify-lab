# Codex OAuth 초기 실험

2026-10-01, Codex CLI 0.159.1의 저장된 ChatGPT 로그인을 사용했다. API 키를 사용하지 않았다. 요청 설정은 빠른 역할 `gpt-6-luna` / low, 검토 역할 `gpt-6-astra` / high다. CLI 이벤트가 실제 반환 모델 ID를 제공하지 않아 요청 모델만 기록했다.

6개 질문 × 4가지 방식 = 24건을 1회 반복으로 실행했다. 총 모델 호출은 42회이며 실패는 0건이다. 정답은 프롬프트에 보내지 않았다. 질문마다 각 방식을 별도로 실행하므로 같은 질문의 초안도 실행마다 달라질 수 있다.

| 방식 | 출력 완전 일치 | 첫 답 중앙값 | 최종 답 중앙값 |
|---|---:|---:|---:|
| 빠른 모델 단독 | 5/6 | 5.23초 | 5.23초 |
| 추론 모델 단독 | 6/6 | 6.42초 | 6.42초 |
| 순차 검토 | 6/6 | 5.17초 | 12.30초 |
| 병렬 독립 풀이 + 검토 | 6/6 | 5.26초 | 12.93초 |

빠른 모델의 주사위 확률 응답은 `1/6`을 LaTeX 수식으로 출력했다. 수학적 값은 정답과 같지만, 요청한 출력 형식과 완전 일치하지 않아 탈락했다. 이를 사실 오류로 해석하면 안 된다. 순차·병렬 실행에서 검토 모델이 초안을 수정한 사례는 없었다.

별도 수정 시험은 의도적으로 넣은 초안 `313`을 검토 모델이 `323`으로 수정하는지 확인했다. 성공했으며, 그 호출과 결과는 `codex-correction.json`에 저장했다. 이 시험은 빠른 모델이 실제로 낸 오류를 발견한 사례와 구분한다.

첫 답 시간은 완성된 답변을 출력한 시점이다. 첫 토큰 시간이 아니다. CLI 프로세스 시작·인증·기본 시스템 프롬프트 비용이 포함된다. USD 비용은 구독 사용량으로부터 추정하지 않고 null로 남겼다. 데모와 별도 수정 시험은 비교 표에 포함하지 않았다. 별도 수정 시험이 비교 실험 초반에 함께 실행되어 일부 시간 측정에 자원 경합이 생겼을 수 있다.

이 실행에서는 순차·병렬 검토가 추론 모델 단독보다 최종 답을 늦게 확정했다. 짧고 쉬운 질문 6개, 반복 1회만으로 일반적인 속도나 정확도 우위를 판단할 수 없다. 다음 실험은 더 어려운 질문과 반복 측정으로 확대하고, 시간 측정 중 다른 모델 호출을 하지 않아야 한다.
